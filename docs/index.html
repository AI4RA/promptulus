Welcome to the AI Literacy Companions

This project is designed to teach you how to think about using AI. Each character highlights an important discipline in the AI workflow.

The advice from any individual character is educational. It should not be used to make definitive judgments about specific tasks. Always consult your institution's policies and use professional judgment.

Do not submit sensitive, confidential, or personally identifiable information unless your institution has an enterprise or data privacy agreement in place with Google. Your inputs are sent to a third-party AI service (Google Gemini) for processing. When in doubt, use generic or anonymized examples when describing your tasks.

How to Get a Gemini API Key

The AI Literacy Companions use Google's Gemini API to power the interactive characters. A free API key is enough to get started.

  1. Visit Google AI Studio and sign in with your Google account.
  2. If this is your first visit, AI Studio creates a project and an API key for you. Otherwise, click Create API Key and pick a project with no billing account attached.
  3. Copy the key and paste it into the input field on this page.

About the free tier

  • No cost, no credit card. A project without a billing account stays on the free tier. If you link billing to the project, usage is charged at paid rates.
  • Rate limits. Free keys allow a limited number of requests per minute and per day. If a character stops responding, wait a minute and try again. Current limits are on Google's rate limits page.
  • Your inputs may be reviewed. On the free tier, Google may use what you type and the responses to improve its products, and human reviewers may read them. Do not enter sensitive, confidential, or personal information.
  • Who can use it. Google's terms require users to be 18 or older, and some regions (including the EU, UK, and Switzerland) have extra restrictions. See the Gemini API terms.

Your key is stored only in your browser's memory for the current session - it is never saved or sent anywhere except directly to Google's API.

Workshop facilitators: You can pre-fill a key by sharing a link with ?key=YOUR_KEY appended. The key is stripped from the URL after loading. Everyone using that link shares one key's rate limit, so a free key will run out quickly with a group. Have participants use their own keys, or use a key on a project with billing enabled.

The AI Literacy Companions

Hello! I'm Octavius. Think of AI like an eager junior employee: brilliant, fast, and desperate to please. They'll do anything you ask without pushing back, even if your instructions are vague or your request doesn't quite make sense. They won't tell you when they're guessing, and they'll never say "I don't know." Using AI well means learning to manage that employee: giving clear direction, providing the right reference materials, and always checking their work. My companions each teach one of these skills.
